# SINSI
Sinais e Sistemas - LEEC, ISEP

Este repositório contem material de apoio às aulas de Sinais e Sistemas do ISEP, Universidade Técnica do Porto.
Para cada sessão de laboratório é apresentada a teoria de suporte e a resolução detalhada de um conjunto de problemas selecionados. Adicionalmente apresentam-se scripts em Python que ilustram uma sugestão de resolução. A linguagem de programação a utilizar pelos estudantes é o Matlab/Octave sendo os scripts em Python material complementar não sujeito a avaliação.
Qualquer sugestão de melhoria ou eventual correção são bem vindas.
